## Building in public: a microservices replica, from scratch

Most of my energy, in my free time, right now goes into **personal projects**, and the direction is deliberate: I want to build a **microservices replica** — a working reference system I can break, instrument, and rebuild — rather than another tutorial-shaped repo.

The plan, roughly in order:
- **Decompose properly** — service boundaries defined by domain, not by convenience
- **Make them talk** — sync HTTP where it's simple, events where it earns its complexity
- **Containerize and ship** — Docker images, CI that actually gates merges, deploys that are boring
- **Provision with Terraform** — infrastructure as code, no clicking around consoles
- **Observe it** — logs, metrics, and tracing so failures are explainable, not mysterious
- **Then do it again smaller** — a local k3s cluster, so the whole thing runs on one machine

I'm documenting the process as I go. Some repos are finished, some are scaffolding, and some are experiments that taught me what not to do — that's the point.
